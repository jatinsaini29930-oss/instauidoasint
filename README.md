# Instagram UID Assistant

A lightweight Python CLI utility for working with Instagram usernames,
public profile URLs, and authorized Instagram/Meta API integrations.

## Features

- Instagram username validation
- Username normalization
- Public profile URL generation
- Basic public profile URL reachability check
- JSON export
- TXT export
- Optional authorized API mode
- Simple terminal menu
- Linux, Windows and macOS compatible

## Important

This project is intended for legitimate and authorized use.

It does NOT:

- Brute-force Instagram accounts
- Guess passwords
- Collect passwords
- Collect OTP codes
- Steal session cookies
- Bypass authentication
- Bypass Instagram security
- Access private accounts without authorization
- Circumvent Instagram rate limits or protections
